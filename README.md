# AdventureWorks Sales Dashboard

## Project Overview
This is an interactive Power BI dashboard built using the Microsoft AdventureWorks dataset. The dashboard provides insights into sales performance, products, customers, and regional sales trends. It was developed to strengthen my skills in Power BI, DAX, data modeling, and dashboard design.

---

## Objectives
- Analyze overall sales performance.
- Track revenue, profit, and orders.
- Monitor product performance and return rate.
- Compare sales across different countries.
- Understand customer purchasing behavior.
- Create an interactive dashboard for business insights.

## Key Insights
- Revenue and profit increased steadily over the selected period.
- Bikes generated the highest number of orders.
- Customer purchasing behavior varies across income groups and occupations.
- The price adjustment feature helps analyze the impact of changing product prices.
- The dashboard helps identify top-performing customers and products.
